# RepoMind — Phase 9.4 Benchmark Report: Abstention Reliability & Exact Endpoint Validation

## 1. Executive Summary

This report documents the empirical benchmark results generated by the RepoMind Evaluation Framework following the completion of **Phase 9.4: Abstention Reliability & Exact Endpoint Validation**.

The evaluation suite was executed across:
- **54 Standardized Retrieval Benchmark Queries** spanning **6 multi-language repositories** (3 real-world open-source subsets and 3 synthetic reference implementations) across Python, TypeScript, and Java.
- **72 Balanced & Labeled Abstention Benchmark Queries** (48 unanswerable out-of-scope queries across 14 defect categories + 24 answerable controls with similar wording).
- **Exact API Route & Method Matcher** eliminating false endpoint grounding across Flask, Express, and Spring Boot.
- **Claim-Level Grounded Answer Generation Evaluations** separating deterministic citation math from generated answer factual support.

## 3. Query-Adaptive Retrieval Routing

In Phase 9.3, RepoMind implements intent-aware query-adaptive routing in `QueryRouter` (`backend/app/retrieval/query_router.py`). Rather than running every engine indiscriminately for every query, the router dynamically selects and prioritizes retrieval streams based on the classified `QueryIntent`:

- **Exact Symbol Lookup**: Prioritizes Keyword search and Graph node coordinates. Bypasses vector semantic drift and caller traversal.
- **Conceptual Questions**: Prioritizes Vector retrieval. Bypasses irrelevant keyword stop-word matching and graph traversal.
- **Caller / Callee Questions**: Prioritizes Graph traversal (`callers` or `callees` operations) and Keyword chunk retrieval. Bypasses vector caller swamping.
- **Inheritance Questions**: Prioritizes Graph traversal (`inheritance` operation) and Keyword chunk retrieval.
- **Dependency Questions**: Prioritizes Graph relationship traversal (`dependencies` operation) and Keyword chunk retrieval.
- **Architecture Questions**: Combines semantic (Vector) and structural (Graph + Keyword) evidence.
- **Mixed / Execution Flow / Impact Analysis**: Engages full hybrid retrieval across Vector, Keyword, and Graph streams.
- **Single-Strategy Overrides**: Strictly preserves pure `vector_only`, `keyword_only`, and `graph_only` modes when requested by the caller.

### 3.1 Impact of Adaptive Routing on Latency & Precision
By eliminating unnecessary engine passes on specific query intents:
- `synthetic_auth_repo`: Hybrid latency decreased from **13.68 ms** to **8.35 ms** (-39.0%), while P@1 increased from **0.6429** to **0.7857** (+22.2%).
- `synthetic_ts_express_repo`: Hybrid latency decreased from **14.81 ms** to **8.93 ms** (-39.7%), while P@1 increased from **0.5556** to **0.7778** (+40.0%).
- `real_world_ky_subset`: Hybrid latency decreased from **11.86 ms** to **5.46 ms** (-54.0%).
