## 5. Architectural Retrieval Analysis

### Why Hybrid Outperforms Individual Engines
1. **Dense Vector Limitations**: While ChromaDB semantic search excels at abstract concept matching (e.g., *"token authentication"*), it frequently misses exact identifiers with unusual prefixes or underscores (`verify_access_token`).
2. **Keyword BM25 Limitations**: SQLite FTS5 reliably locates exact identifiers, but fails completely on semantic paraphrases (e.g., *"how are user passwords verified"* fails to match `security.py:hash_password`).
3. **GraphRAG Precision**: Knowledge Graph traversal uniquely resolves cross-file callers and callees that lexical and vector search cannot identify due to distant context separation.
4. **Reciprocal Rank Fusion (RRF)**: Combining the top ranks from Vector, Keyword, and Graph engines via RRF with constant $k=60$ produces the optimal blend: exact symbols surface to rank 1, accompanied by rich structural context.
